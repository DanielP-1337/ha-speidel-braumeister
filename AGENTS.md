# Beta App Store publication

This `beta` branch is the user-facing HA App Store channel. Keep its URL stable.
For every future Bridge beta publication, advance this branch only to a tested
release, preserving repository.yaml metadata and the app's Beta display name.
See docs/app-store-beta.md. Do not silently publish development commits here.
Do not start the old local Bridge and this app simultaneously on the HA host.
